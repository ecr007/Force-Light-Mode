Privacy Policy for Force Light Mode

Last updated: September 27, 2025

Introduction

Force Light Mode is a Chrome extension that allows users to switch websites to a light theme. This extension respects your privacy and does not collect any personal data or track your browsing activity.

Information We Collect

Force Light Mode does not collect, store, or share any personally identifiable information. The extension only accesses the current active tab to apply styling when the user clicks the extension icon.

Permissions

  • activeTab: Used to apply light mode CSS to the current tab when the user activates the extension.
  • scripting: Used to dynamically inject the CSS for the light mode.

Third-Party Services

Force Light Mode does not use or integrate with any third-party services or analytics tools.

Data Security

No user data is stored or transmitted. All operations are performed locally in your browser.

Changes to This Privacy Policy

We may update this privacy policy from time to time. Any changes will be posted on this page.
